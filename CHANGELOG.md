# Changelog

- Changed the interface accent from lavender to blue.
- Added green/red status indicators for active and inactive filtering.
- Added a master **Disable distractions** control that reveals the distraction checklist when enabled.

- Added a thin, light panel border to separate Serein from YouTube's page.
- Replaced the app mark with a clean red leaf on white, matching the requested YouTube-inspired palette.
- Kept the original bottom-left launcher and disabled-style symbol.
- Kept light mode as the default and retained the existing white light-theme surface.
- No new permissions or dependencies.
