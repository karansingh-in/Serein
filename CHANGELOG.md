# Changelog

## 3.0.0

- Rebuilt the settings interface with a minimal, light-first visual system and muted lavender accent.
- Replaced the floating bottom-left launcher with a text **Filters** control beside YouTube's search bar.
- Introduced the lowercase spaced wordmark `s e r e i n` and linked **Built by karansingh-in** footer credit.
- Removed page-specific filtering, separate channel lists, watched/live/upcoming/duration filters, playback speed, viewing-time tracking, break reminders, focus presets, and the large distraction checklist.
- Kept keyword blocking and inclusion, Shorts handling, recommendation hiding, optional end-screen/comments hiding, autoplay control, theme selection, and the existing optional recreation schedule.
- Consolidated legacy channel lists into keyword lists during settings migration.
- Preserved the Firefox extension ID, storage key, and storage-only permission.
