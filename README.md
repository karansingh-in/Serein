# Serein

**Keep what matters. Remove the noise.**

Serein is a lightweight, local-only Firefox extension that cleans up YouTube. It supports title/channel keyword blocking and inclusion, Shorts controls, and optional distraction controls.

When **Disable distractions** is enabled, Serein hides YouTube's hamburger, Home and Subscriptions guide entries, homepage topic chips, the right-side masthead controls (Create, notifications and account avatar), and Join/Gemini controls on watch pages. It keeps the Serein home link, the You destination, search and microphone available. The search field expands into the freed header space. Turning distraction mode off restores the elements Serein hid.

Settings are stored locally. No analytics, telemetry, accounts, remote services, or additional permissions are used.

## Install in Firefox

1. Extract the release ZIP.
2. Open `about:debugging#/runtime/this-firefox`.
3. Choose **Load Temporary Add-on** and select `manifest.json`.
