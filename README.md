# Serein

**Keep what matters. Remove the noise.**

Serein is a lightweight, local-only Firefox extension for filtering YouTube videos and reducing interface distractions.

When **Disable distractions** is enabled, Serein hides the guide/sidebar, topic suggestion chips and YouTube's right-side masthead controls. It relocates a **You** shortcut and the Serein filters control into the top-right masthead, immediately after the search and microphone area. The homepage content reclaims the sidebar width; native thumbnail dimensions are left to YouTube to avoid cropping.

The Serein wordmark links to the YouTube homepage. The **You** shortcut opens `/feed/you`. Settings are stored locally. No analytics, telemetry, accounts, remote services, or additional permissions are used.

## Install in Firefox

1. Extract the release ZIP.
2. Open `about:debugging#/runtime/this-firefox`.
3. Choose **Load Temporary Add-on** and select `manifest.json`.
